# 신뢰성분석 & 추세분석기 (통합 웹앱)

원본 데스크톱 프로그램 2개(tkinter)를 Streamlit 웹앱으로 옮긴 것입니다.
사이드바에서 아래 2가지 중 하나를 선택해서 사용합니다.

## ① 신뢰성분석 (가속시험 통합계산기)
- 탭① 온도가속(Arrhenius)
- 탭② 온습도가속(Arrhenius-Peck)
- 탭③ 열피로가속(Thermal Cycling)
- 탭④ Weibull 시험시간비 계산기 + 참고 DB
- 탭⑤ 수명데이터 분석(Weibull MLE) + 확률도표

## ② 추세분석기 (내구시험 Raw Data 분석)
- 전체 추세: 여러 CSV 파일의 항목별 통계(평균/최대/최소/동작구간 중앙값 등) 추세, 회귀/임계값 예측
- 정밀 분석: 특정 누적 작동시간(h)에 해당하는 raw 파형(0.1초 간격)을 확대/이동해서 보기
- 두 시간대 비교: 서로 다른 두 시점의 파형/통계 비교
- 새 파일 비교(폴더감시 대체): 새로 쌓인 CSV를 다시 업로드해서 이상치(평균±Nσ) 탐지
- 신뢰성 분석(TTF·RUL): 스펙(LSL/USL) 이탈 시점(TTF) 탐지 + 추세모델 기반 잔여수명(RUL) 예측

### ⚠ 원본과 다른 부분 (웹 환경 제약)
원본 프로그램의 "폴더 감시" 탭은 사용자 PC 폴더를 백그라운드에서 실시간으로 감시합니다.
브라우저 기반 웹 서비스는 로컬 폴더를 감시할 수 없고, 서버를 24시간 계속 띄워두는 것도
무료 배포 환경에서는 어렵기 때문에, 이 기능은 **"새로 생긴 CSV들을 다시 업로드해서
그 자리에서 비교"**하는 방식(수동 새로고침)으로 대체했습니다. 이상탐지 판정 기준
(평균 ± Nσ)은 원본과 동일합니다. 나머지 4개 탭은 원본과 동일한 계산 로직을 사용합니다.

## 로컬 실행
```
pip install -r requirements.txt
streamlit run app.py
```
브라우저가 자동으로 열리며, 기본 주소는 http://localhost:8501 입니다.

## 구성 파일
- `app.py` : 진입점(사이드바에서 ①/② 선택)
- `reliability_app.py` / `reliability_calc.py` : 신뢰성분석(가속시험 계산기) 화면/로직
- `trend_app.py` / `trend_calc.py` : 추세분석기(Raw Data 분석) 화면/로직
- `requirements.txt` : 설치 패키지 목록
